Connect an AI tool

StudConS speaks MCP over HTTP, so any MCP-compatible AI assistant can query it directly — no code required on your end.

Server URL

• No authentication — this is an open demo server

• Transport: Streamable HTTP (current MCP standard)

Set up in Claude

  1. 1Open the toolbox icon in the sidebar, then Customize → Connectors
  2. 2Click +, then Add custom connector
  3. 3Paste the server URL above, set auth to No sign-in, and click Add
  4. 4Enable it for your chat from the + menu, then ask a question

Available tools

get_attendance Subject-wise attendance for a student
get_cgpa CGPA and backlog count for a student
check_eligibility Whether a student qualifies for a company's drive
list_placement_drives All upcoming drives and their criteria
