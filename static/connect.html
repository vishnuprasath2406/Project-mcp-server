Connect an AI tool

StudConS speaks MCP over HTTP, so any MCP-compatible AI assistant can query it directly — no code required on your end.

Server URL

Copy this and add it as a remote connector.

Claude (claude.ai / Claude Desktop)

  1. Open the toolbox icon in the sidebar, then Customize → Connectors
  2. Click +, then Add custom connector
  3. Paste the server URL above and click Add
  4. Enable it for your chat from the + menu, then ask Claude something like "What's the attendance for CS101?"

Other MCP-compatible tools
